# E-Portfolio — Joan GUILBERT

Portfolio numérique personnelle développée dans le cadre de mon **BUT Informatique** à l'IUT Grand Ouest Normandie. Ce site rassemble mon profil, mes compétences, mes projets ainsi que mes différents moyens de me contacter.

***Consulter le site en ligne :*** [goldenblac-k.github.io/E-Portfolio](https://goldenblac-k.github.io/E-Portfolio)

## Architecture de la page

La navigation se découpe en quatre sections :

* **Accueil** - En-tête fixe avec barre de navigation animée et introdution au site.
* **Profil** - Synthèse de mon parcours, de mes compétences, grille interactive et accès direct à mon CV.
* **Galerie** - Carrousel pour explorer mes projets avec images, descriptions et liens vers leurs dépôts.
* **Contact** - Liens vers mes réseaux professionnels, adresse mail et copyright.

## Réalisation technique

Le site est entièrement conçu sans framework ni bibliothèque externe, afin de conserver un contrôle absolu sur le code, les performances et le rendu.

* **HTML5** - Structuration du site.
* **CSS3** - Style des éléments.
* **JavaScript** - Animations et déclencheur d'événements.
